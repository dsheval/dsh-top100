# 1.3.9 简介持续展示与榜单更新

本版让官网和插件统一展示中文简介的来源状态：资料发生变化时，符合条件的旧简介保留日期和待核查提示；身份变化、明确错误或撤回的内容继续隐藏。普通文案更新仍由服务端发布，本次客户端升级用于新的状态提示和榜单展示。

- 区分人工复核日期与模型生成日期；搜索、推荐、已安装列表与榜单使用一致的显示规则。
- 模型简介保留最多三个有来源证据的版本，来源变化先待复核；经确认仍准确则复用，需要修改才进入原有生成流程。失败与重启保留历史和重试状态。
- 补齐经来源核对的插件及 Skills 中文，Skills 前 100 可通过独立日常开关进行来源复查与缺口处理。身份不清、固定暂停及无效输出不自动放行。
- 更新热度榜与新锐榜的增长窗口和分数曲线，保留实际 Stars 观测时间。历史快照过渡采用固定截止日期，来源与局限在排名方法中说明，不随重启延期。
- 改善大目录同步及发布内存占用，并加入生产规模的离线回归和 CI 内存限制检查。

本地类型检查、1736 项测试及 8 项安装包检查通过；插件构建、实际候选包完整性和依赖审计通过。Linux CI、真实宿主升级和生产上线结果在正式发布时单独验收，不能以本地检查替代。

此版本不增加 DeepSeek 自动语义复核调用，不扩大共享日/月预算，也不启用榜外整批重生成。普通简介修订无需反复升级客户端；完全离线时仍无法获知服务器上的后续更新。
