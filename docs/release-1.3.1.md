1. 本地预览代理未转发压缩协商，大索引读取曾超时；直接联网的 DSH 请求也未得到稳定成功结果。使用 curl 压缩下载已成功，随后以校验一致的快照完成真实宿主功能验收。正式发布前应在可稳定访问生产数据源的环境补做首次无缓存的全库搜索验证。
2. PR 创建后等待远端 CI，审查完整变更范围，再从合并后的确定提交发布 npm、标签及 Release。
3. 服务器升级前备份运行数据，部署同一版本后检查榜单、搜索、安装命令及采集服务；本次没有运行生产采集任务。
