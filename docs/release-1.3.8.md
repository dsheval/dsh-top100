# 1.3.8 服务端统一中文简介

此前插件内置的复核文案可能覆盖服务器修订。本版改为由服务器统一发布最终简介，官网与插件读取同一结果；完成本次升级后，普通简介修改、新增复核和撤回不再要求发布插件新版。

- 将复核表、来源绑定和质量规则集中到服务端；固定复核内容及已批准来源证据保持。
- 完整榜单、分片、分类分页、Skills 和紧凑搜索统一发布最终文案及状态，最终结果参与快照标识计算。
- 移除插件和官网的复核覆盖逻辑，空文案与待复核结果不借原始描述或安装包元数据补回。
- 修复刷新并发及旧协议回退路径；已收到新快照后，离线缓存不能恢复更旧的简介。
- 保留 30 分钟缓存和手动刷新。旧数据没有新协议标记时保留排名与安装信息，中文简介显示待生成；完全离线时无法获知尚未收到的服务器更新。

发布准备已通过本地类型检查、1655 项测试（1 项 Linux 专用跳过）及 8 项安装包检查。同一个实际候选安装包通过 12 种服务端内容变更场景，包哈希和版本始终不变。真实宿主、CI 和生产发布结果以本次发布验收为准。

模型、预算和定向处理限制不变；这次发布准备没有调用付费模型。插件功能、界面、宿主兼容性或不兼容数据协议的变化仍可能需要后续软件升级。
