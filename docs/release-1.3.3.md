# 1.3.3 发布说明与验收范围

本版修复“没有新版仍可执行更新”，并完善批量更新、原更新频道保留与全局 Skill 的本地修改保护。

## 主要变化

- 已最新、较旧版本和相同 GitHub commit 不再产生可执行更新；检查失败可刷新重试，列表显示检查状态。
- 默认保留 npm 版本范围、频道和 GitHub 分支；切换最新版需明确选择。旧 beta/latest 声明经确认后固定到当前已安装版本并保留频道，防止更新其他包时顺带升级。
- 每组检查 20 项，单次最多 200 项，成功项目统一确认，失败和无需更新逐项说明。慢网检查完成后再统一开始确认有效期。
- Skill 替换、卸载前完整备份目录和本地新增文件，显示全局作用域、修改状态与备份位置，保护失败恢复期间的外部修改。
- 修复 Profile 参数、Skill 元数据、重试入口、英文诊断、窄面板按钮与对话框键盘焦点。
- Vitest 升至 4.1.11；修复相关开发依赖漏洞。

## 验收基线

本轮功能候选通过 `npm run check`：Collector 113、插件 645、网页 77，共 835 项；类型检查、插件构建和依赖审计通过，审计为 0 漏洞。

真实集成环境为 DSH 0.1.2-rc.1、Node 24.20.0、pnpm 11.24.0 与 Chrome 152。隔离 DSH Web Profile 已验证同版本无操作、24 项批量升级及重启生效、旧频道整理与未选插件保护、Skill 本地文件备份、英文诊断和键盘焦点。业务测试使用受控 npm fixture，不修改用户实际 Profile。

正式发布需核对最终提交的远端 CI，从该提交构建 1.3.3 包并做隔离安装烟测；发布后核对 npm `latest`、完整性及下载内容。版本状态与最终校验信息以 [GitHub Release](https://github.com/dsheval/dsh-top100/releases/tag/v1.3.3) 和 [npm 版本页](https://www.npmjs.com/package/@dsheval/dsh-top100-plugin/v/1.3.3) 为准。

## 使用边界

- Windows、DSH Desktop、最低兼容宿主、真实 GitHub 分支下载及完整屏幕阅读器流程未实测。
- 旧频道整理支持独立 Profile 的 pnpm v9 锁文件；复杂 workspace、自定义 hook 或不一致的元数据会被拒绝，需手动维护。
- Skill 互斥锁覆盖单宿主进程。旧频道整理不保证掉电或进程强杀时跨文件原子提交，极端中断可能需恢复保留的 `.bak`。
- 部分 pnpm 环境要求新包发布满 24 小时；需要立即安装时，按 README 为本版本配置精确例外。

本次 npm 插件发布与官网、采集服务的服务器部署分开执行。
