# 1.3.6 安装反馈与排名修复

本版改善插件与 Skill 的安装、更新、卸载反馈，沿用 1.3.5 的 DSH 0.1.5-rc.2 兼容基线。

- 使用实际依赖计数及网络重试说明，移除估算百分比；修复进度日志跨数据块时计数丢失，分别缓冲两路输出，保留跨块中文及最终残行。
- 按实际操作区分进行中、成功、失败、取消文案；显示构建受阻依赖、实际 Profile 目录和回滚结果，并提供构建授权恢复指南。
- 最近操作保留最近 10 批已完成任务，集中展示结果并移除重复提示；宿主重启后已完成记录过期不再误报失败，未知结果与真实网络错误分别处理。
- 统一任务字体与间距，保持现有页面结构；不增加自身管理聚合面板。
- Top100 自身在正式排名评分及截断前排除；官网与插件兼容过滤旧快照。旧截断快照可能暂缺一项，新生成榜单才会补齐。
- 补充源码首次准备、日常启动及构建失败恢复文档。

完整本地检查通过：采集器 584、插件 822、官网 93 项测试，共 1,499 项；类型检查、插件构建及依赖审计通过，审计 0 漏洞。发布前另对实际归档执行隔离 DSH Web 0.1.5-rc.2 验证。

本版不保证所有第三方插件均能安装。网络问题、宿主依赖和构建脚本授权仍取决于实际环境；最近操作不是跨宿主重启永久保存的历史。Windows 与 DSH Desktop 本轮未进行真实宿主复测。付费模型生成继续暂停。
