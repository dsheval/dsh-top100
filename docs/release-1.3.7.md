# 1.3.7 中文简介与来源复核修复

当 README 开头是致谢、安装条件或配图说明时，旧流程可能把其中一句中文当作已完成简介并缓存。本版移除这种回退路径，将可识别的问题内容标记为待复核，避免后续更新继续恢复旧文案。

- 对两榜 36 条介绍进行定向修订，并绑定已核对的资料及具体收录对象。身份或资料不足的记录保留待复核状态与原因。
- 网站、插件、每日更新和缓存使用一致的复核规则；错误缓存、已完成作业与历史快照不能覆盖明确撤回的内容。
- 本批资料绑定覆盖 README 全文哈希，避免只比较短摘要遗漏后半部分的变化。无关根项目宣传语变化不会使已核实子包的介绍失效。
- helm-d 的 bootstrap 包只有在三个固定源码文件核验通过后才恢复相应介绍；已有其他源码证据基线保持不变。
- 新增来源、日常补齐、预算及重试范围沿用既有配置；修正规则不会触发全库付费重写。

本地完整检查通过 1,624 项测试，1 项 Linux 专用检查在本地跳过；另验证插件构建，以及旧快照 134 个项目和 36 个最新来源的离线回放。最新来源中 dsh-mneme 因包目录迁移被暂停复用；这不等于旧快照下的介绍已获准用于新目录。

本版不保证未来所有简介都能自动完成语义核验。待复核不是可安装或运行失败结论；第三方插件仍需按其文档配置。Windows 与 DSH Desktop 本轮未进行真实宿主复测。
