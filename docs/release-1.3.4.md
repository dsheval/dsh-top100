# 1.3.4 发布说明

本次修正中文介绍和功能分类与实际收录对象不一致的问题，完善安装来源状态，并统一官网与 DSH 插件的榜单展示。

- 中文介绍与固定分类绑定收录包及子目录，明确撤回的错误内容不会被旧缓存恢复。缺源、身份不清的项目保持待复核。
- 安装来源区分已识别、清单预检通过、未通过、暂未确认和过期；预检不等于实际安装或宿主运行成功。
- Top100 与新锐榜分别统计当前榜单分类数量，分页不改变总数；分类筛选保留对应榜单的原名次。插件排序入口统一为 Top100。
- 仓库发现支持工作区子包，候选来源部分失败保留已取得的结果。私有仓库不进入公开目录，未确认结构不冒充已验证。
- 模型补齐暂停，残留 Key 不应触发付费调用。每日公开数据采集、排名计算、已有有效内容复用与模型生成分别处理。完整金额预算及功能内容增量策略尚未完成验收，不随本次发布恢复付费生成。

## 使用与边界

安装方式沿用 [插件 README](../plugin/README.md)。此次升级针对 Top100 插件与目录服务，不需要批量修改榜单中的第三方插件。现有生成候选与固定复核不代表全库经过真人验收；缺失中文、未确认分类和未核验来源仍明确展示其状态。

本地已验证官网交互、真实隔离 DSH Web 中的插件加载、分类计数和已有快照内容一致性。最后的小幅展示修改有对应网页回归和客户端构建验证。提交后的 CI、发布包完整性、服务器数据保留和公网结果仍需在对应发布步骤核对；本说明不代替远端发布状态。

升级服务器时先备份现有运行数据，保留原榜单顺序、涨幅与数据库历史，再按来源身份合入内容修订。模型预算防护验收前保持补齐暂停，不能因部署启动全库重新生成。
