01 · Quick start

下载 dsh-Top100 并接入 DSH

从 GitHub README 点击“一键下载”会直接来到本页。这里不提供独立安装包；请选择与你启动 DSH 相同的方式，复制命令即可从 npm 安装插件。

使用 npx 安装 DSH Web
npx @deepseek-ai/dsh plugin --profile web add @dsheval/dsh-top100-plugin
安装后启动 npx @deepseek-ai/dsh web

请在 DSH 源码仓库外运行以上命令。启动后打开 设置 → 插件排行。

从 DSH 源码安装 DSH Web
先进入源码仓库cd /path/to/deepseek-harness
pnpm dsh plugin --profile web add @dsheval/dsh-top100-plugin
安装后启动 pnpm dsh web

请将示例路径替换为本机 DSH 源码仓库的实际绝对路径，并在仓库根目录执行后续命令。

如果终端执行 dsh --version 可以正常返回，也可以使用 dsh plugin --profile web add @dsheval/dsh-top100-plugin，并以 dsh web 启动。

npx 已知问题

部分 npm 环境可能在首次解析 DSH 依赖时长时间无输出并持续占用 CPU。该问题发生在 DSH npm 发布包的依赖解析阶段，并非 dsh-Top100 插件安装失败。如果 npx @deepseek-ai/dsh --version 也无法完成，请停止命令并改用源码方式。不要单独添加 --legacy-peer-deps，否则可能漏装 DSH 运行时依赖。参见 DSH 上游讨论。

当前版本：@dsheval/dsh-top100-plugin@1.0.1 已发布到 npm。运行环境需要 DSH Web 0.1.0-rc.6+ 和 Node.js 22.13+。

02 · Features

在 DSH 内查找插件并确认安装可信来源

01

发现插件

浏览 Top 100、新锐榜、总榜和分类榜，并按名称或标签快速搜索。

02

确认安装

仅对作者明确提供且验证通过的安装源，在 DSH 设置页内进行单项确认安装。

03

对话推荐

内置 recommend-dsh-plugins Skill，可按你的需求实时搜索市场并推荐合适插件。

在 DSH 对话中直接询问“我应该安装哪个插件”即可触发推荐；Skill 通过只读的 dsh_top100_search 工具查询榜单。安装包只包含 DSH 插件及该 Skill，不包含采集程序、数据库或网站后端。

03 · Data Source

与 DSHeval 官网使用同一份数据

DSHeval 服务器 rankings.json DSH 插件 插件排行页

榜单数据来自 https://www.dsheval.ai/data/rankings.json，由 DSHeval 服务器持续更新。 插件与网页版共用这份数据，因此榜单、分类和项目详情会保持一致；数据由插件 Host 获取并缓存在本地。
