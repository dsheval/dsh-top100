01 · Quick start

一条命令，接入 DSH

将下面的命令粘贴到终端即可完成安装。

Install command DSH Web
dsh plugin --profile web add @dsheval/dsh-top100-plugin

安装完成后重启 dsh web，打开 设置 → 插件排行。

当前版本：@dsheval/dsh-top100-plugin@1.0.0 已发布到 npm。运行环境需要 DSH Web 0.1.0-rc.6+ 和 Node.js 22.13+。

02 · Features

在 DSH 内查找和安装插件

01

发现插件

浏览 Top 100、新锐榜、总榜和分类榜，并按名称或标签快速搜索。

02

直接安装

在 DSH 设置页内对可信来源进行单项确认安装，无需部署榜单后端。

03

对话推荐

内置 recommend-dsh-plugins Skill，可按你的需求实时搜索市场并推荐合适插件。

在 DSH 对话中直接询问“我应该安装哪个插件”即可触发推荐；Skill 通过只读的 dsh_top100_search 工具查询榜单。安装包只包含 DSH 插件及该 Skill，不包含采集程序、数据库或网站后端。

03 · Data Source

与 DSHeval 官网使用同一份数据

DSHeval 服务器 rankings.json DSH 插件 插件排行页

榜单数据来自 https://www.dsheval.ai/data/rankings.json，由 DSHeval 服务器持续更新。 插件与网页版共用这份数据，因此榜单、分类和项目详情会保持一致；数据由插件 Host 获取并缓存在本地。
