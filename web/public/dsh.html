安装步骤

3 步完成安装

不需要下载压缩包。打开终端（macOS 终端或 Windows PowerShell），依次复制下面两条命令，然后在 DSH 中打开插件排行。

开始前 已能启动 DSH Web 可直接继续；首次安装需要 Node.js 22.13+。普通用户不要在 DSH 源码仓库内执行以下命令。
  1. 1

    安装 dsh-Top100

    复制并运行这条命令。它会把插件添加到 DSH Web。

    npx @deepseek-ai/dsh plugin --profile web add @dsheval/dsh-top100-plugin
  2. 2

    启动 DSH

    安装完成后，在同一个终端继续运行：

    npx @deepseek-ai/dsh web
  3. 3

    打开插件排行

    浏览器打开 DSH 后，进入：

    设置 → 插件排行

按需展开

其他运行方式与问题排查

我从 DSH 源码运行（开发者）

先用 cd /你的/DSH/源码路径 进入仓库根目录；确认已经替换示例路径后，再依次执行：

pnpm dsh plugin --profile web add @dsheval/dsh-top100-plugin
pnpm dsh web
我的电脑已经安装全局 dsh 命令

如果 dsh --version 能正常返回，可以直接使用：

dsh plugin --profile web add @dsheval/dsh-top100-plugin
dsh web
npx 长时间没反应怎么办？

部分 npm 环境可能在首次解析 DSH 依赖时长时间无输出并持续占用 CPU。这个问题发生在 DSH npm 包的依赖解析阶段，并不代表 dsh-Top100 安装失败。

如果 npx @deepseek-ai/dsh --version 也无法完成，请停止命令并改用上面的源码方式。不要单独添加 --legacy-peer-deps，否则可能漏装 DSH 运行时依赖。参见 DSH 上游讨论。

当前发布版本：@dsheval/dsh-top100-plugin@1.1.1，已发布到 npm（latest），适配 DSH Web 0.1.0-rc.6+。

01

发现插件

按综合热度、新锐或 Stars 浏览插件，以分类独立筛选，并按名称或标签快速搜索。

02

管理安装

查看中文简介，并对作者明确提供且验证通过的安装源进行单项确认安装。

03

对话推荐

直接询问“我该装哪个插件”，内置 Skill 会根据实时榜单给出推荐。

插件安装包只包含 DSH 插件及 recommend-dsh-plugins Skill，不包含采集程序、数据库或网站后端。
