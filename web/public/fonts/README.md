# EvalDock navigation font

Inter is used only by the global header and footer to match the EvalDock website (commit `b8c201b`). Content typography retains Top100's existing system font stacks.

Source: `google/fonts`, revision `a54f7446f84a1125ef6bf08baa46f3639e8905e0`, `ofl/inter/Inter[opsz,wght].ttf`. The Latin WOFF2 subset is copied without modification from the website. The OFL license is included as `inter-OFL.txt`.
